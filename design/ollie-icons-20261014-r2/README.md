# Ollie icon concepts — round 2

Five deliberately different app-icon directions, generated with the built-in ImageGen tool after an Opus 5.5 design consultation.

- A — Pocket Otter: a calm sculptural companion.
- B — Switch: a large red physical control.
- C — Smoke Portal: an aperture in smoky glass.
- D — Ollie Deck: a skateboard jump, a playful reference to the name.
- E — Shift: a blue geometric stepped mark.

Open `index.html` for the interactive comparison, enlarged views, and 32/64 px samples. Generated masters are preserved without image editing. `prompts.json` records the full generation prompt for every candidate. `opus-consult.md` contains the independent advice and `opus-brief.md` preserves the review brief.

Marijn selected **A — Pocket Otter**. The generated image is preserved here; the installed master is `../../release/Icon.png` at 1024px, with all ten macOS asset slots regenerated by `../../scripts/gen-app-icon.js`. The menu bar uses the simpler monochrome head in `../../Ollie/Assets.xcassets/MenuBarIcon.imageset/otter.svg`, replacing the former bolt.
