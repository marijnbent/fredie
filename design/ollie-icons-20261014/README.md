# Ollie icon directions

Open `index.html` for the interactive comparison. Click an icon to enlarge it; switch Dark / Light to check the surrounding background.

- A — Smoke: smoky glass and an ivory bolt. Recommended by Opus and the primary agent.
- B — Ceramic: bone ceramic and a deep red glaze.
- C — Signal: chartreuse and a solid ink bolt.
- D — Keycap: a dished silver keyboard key with a printed bolt legend.

Each direction has a 1024 × 1024 SVG source and transparent PNG master. `small/` contains dedicated 16, 32, 64 and 128 px SVG/PNG previews; the smallest sizes remove material effects and enlarge the mark slightly.

The existing menu-bar SVG path is preserved exactly. These are deterministic vector concepts with raster exports, not generated bitmap replacements. The app asset catalog and installed app are unchanged.

`opus-consult.md` records the completed consultation from the original Opus conversation, resumed after the project moved to `/ollie`.
