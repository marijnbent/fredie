# Ollie otter variants — round 3

Review options following the rejection of the first menu SVG. Marijn selected **A + 1**: Happy Pocket with the Whiskers mark. Build 31 uses that pairing.

Three new character variants use the built-in ImageGen tool and the selected Pocket Otter as an image reference. Generated masters are preserved without raster editing.

- A — Happy Pocket: a smiling head tilt, bright eyes, and tiny tongue.
- B — Sleek: an upright, slimmer otter with a visible tapered tail.
- C — Floating: a content otter reclining on its back.
- Current: the calm Pocket Otter from build 30, kept as the comparison baseline.

The four menu marks are original SVG drawings with an 18pt intrinsic size and a 24-unit viewBox. They are one-color artwork suitable for template rendering, without shading or bitmap tracing.

1. Whiskers — a broad outlined face with low ears and one pair of whiskers.
2. Little Smile — eyes, whisker pads, and nose with no head outline.
3. Peek — a side profile rising from one water line.
4. Curl — a curled otter silhouette that also suggests an O.

Open `index.html` to compare them, switch the backdrop, enlarge the character images, and preview any pairing. Menu samples appear at 16px and 18px in both light and dark. `prompts.json` records all generation prompts. The Opus brief and advice are included alongside the assets.
