# Navigation

Settings → Navigation enables **Search Menu Bar Items**. The command searches the front app's
menu bar and invokes the selected item through Accessibility. It ships off; recorded shortcuts
also respect the feature switch.

The pane includes the command shortcut, an app exclusion list, and an option to include Apple menu
items. These preferences travel in settings backups. See [menu-search.md](menu-search.md) for
ownership, cancellation, permission checks, and verification.

Window positioning, layouts, and rooms live separately under Window Management.
